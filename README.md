# 📐 Умная Математика (Math for Kids)

Интерактивный развивающий веб-портал для детей, обучающий математике через весёлые игры, визуализацию и геймификацию. Создан на современном стеке **Next.js 16 (App Router)** и **Tailwind CSS**.

---

## 🎮 Доступные Игры

1. 🎈 **Лопай Шарик!** — Решайте примеры на сложение, вычитание, умножение и лопайте правильные шары с комбо-серией.
2. 🍎 **Фруктовый Сад** — Визуальный счёт предметов для малышей от 4 до 6 лет с интерактивной подсветкой.
3. 🚀 **Космическая Гонка** — Тренировка устного счёта на скорость в космической дуэли с пришельцем.
4. 🃏 **Магическая Память** — Поиск математических пар карточек (пример ↔ верный ответ).
5. 🍕 **Шеф-Повар Пиццы** — Интерактивное изучение простых дробей (1/2, 1/4, 3/4) через приготовление пиццы.
6. 🚂 **Волшебный Поезд** — Логические цепочки чисел и поиск пропавшего вагончика (+2, +5, +10).

---

## ✨ Особенности

- 🔊 **Звуковые эффекты без внешних файлов**: Синтез через Web Audio API (лопание шариков, монетки, фанфары, клики).
- 🗣️ **Озвучка заданий**: Встроенная поддержка чтения примеров вслух через Web Speech API.
- 🪙 **Система геймификации**: Опыт (XP), уровни, звёзды, монеты и ежедневная серия дней.
- 🛍️ **Магазин наград и стикеров**: Заработанные монеты можно тратить на новые шляпы, кубки и значки.
- 🏆 **Комната достижений**: Медали за успехи и новые рекорды.
- 🦁 **Выбор аватаров**: Разнообразные персонажи (Лёва, Космонавт, Умный Лис, Робот и др.).
- 💾 **Автономность**: Полная работа без бэкенда — сохранение прогресса в `localStorage`.

## 🚀 Запуск проекта

Установите зависимости и запустите локальный сервер разработки:

```bash
npm install
npm run dev
```

Откройте в браузере [http://localhost:3000](http://localhost:3000).
